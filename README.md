# JakX C Kernel/ELF Decompilation

This repository tracks the effort to finish what [Yodaxtah started](https://github.com/yodaxtah/jak-x-elf-decryption) in decompiling
the Jak X Elf (and eventually Underlord.IRX).
In this repository there is one massive file containing all of the C-like pseudocode for the ELF 
that has been decompiled up to this point.
You should probably use CTRL-F in the editor to jump to the functions that interest you.
Then you can verify that this pseudocode corresponds to the .CPP functions in the PR to
implement the Jak X kernel functions for OpenGOAL.
